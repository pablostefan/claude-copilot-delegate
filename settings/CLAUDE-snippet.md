
# Orquestração e economia
- Você é orquestrador: trabalho mecânico (boilerplate, testes, refactor repetitivo, docs, varreduras) vai para o Copilot via `cop` (skill `copilot-delegation`). Você planeja, revisa o diff e roda a verificação.
- Para revisar, use `git diff --stat` e leia só os trechos que importam. Não releia arquivos inteiros sem motivo.
